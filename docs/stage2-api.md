# Stage 2 API contracts

All endpoints serve actual PostgreSQL data. Responses use allowlisted DTOs, `Cache-Control: no-store`, `X-Robots-Tag: noindex, nofollow`. Plain text only. Errors contain a code, never DB messages, answers, tokens or auth detail. Mutations require exact configured Origin; JSON has bounded streaming reads and strict Zod shapes. No client-supplied ownership/role/approval fields are accepted.

| Method / path                 | Input / output                                                   | Access                                                                                                                             |
| ----------------------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| GET `/api/catalog`            | `locale=en                                                       | uk                                                                                                                                 | fr`, bounded `search`, `category`, `tag`, `sort=featured | new | title`, `page`; six item DTOs + count | Approved, complete published snapshots; adult gate applied before metadata query |
| GET `/api/quizzes/:versionId` | `{versionId, document}`; immutable ordered content               | Same catalog eligibility; missing/draft/archived/ungated ID => 404                                                                 |
| POST `/api/age`               | `{adult:true}` => `{confirmed:true}`                             | Origin + rate check; issues/reuses secure verifier-backed cookie, records self-declaration                                         |
| POST `/api/solo`              | `{versionId}` => `{id}` (201)                                    | Authenticated user or securely established guest; published/age eligibility                                                        |
| GET `/api/solo/:id`           | id/versionId/revision/status/expiresAt/document/responses/result | Own solo attempt only; absent credential, wrong user, expired/revoked => 404                                                       |
| PUT `/api/solo/:id`           | `{versionId, revision, responses}` => revision/status            | Own, editable attempt; whole validated partial set atomically replaces answers; stale revision => 409 CONFLICT                     |
| POST `/api/solo/:id`          | Same full answer shape => revision/status                        | Required responses checked, unique result created, freezes answers; idempotent after submission                                    |
| POST `/api/drafts`            | `{}` or `{sourceId}` => `{id}` (201)                             | Authenticated author; source must be theirs; cloning never mutates source                                                          |
| GET `/api/drafts/:id`         | id/status/revision/document/translation deficiencies             | Owner only, age gate for adult content                                                                                             |
| PUT `/api/drafts/:id`         | `{revision, document}` => new revision + deficiencies            | Owner, DRAFT only; validates references, selections, image ownership, category/tags; blank translations allowed in drafts          |
| POST `/api/drafts/:id`        | `{revision}` => PENDING                                          | Owner; saved complete translations required; freezes author edits; no approval endpoint                                            |
| POST `/api/media`             | Raw PNG/JPEG/WebP body, max 5 MiB, exact MIME => `{id}`          | Authenticated, rate limited, signature/decoder/pixels/time bounded; metadata stripped, private WebP storage                        |
| GET `/api/media/:id`          | Private WebP bytes                                               | Asset owner or approved published reference; adult gate also applies to linked adult media; no signed secret URL/public object URL |

Responses are discriminated by question type: SCALE has `{questionId,type,value}` (integer 1..5); choice kinds have `{questionId,type,options:[optionUUID...]}`. Unknown fields, question IDs, kinds, option IDs, duplicate responses/options and invalid bounds are rejected. No free-text answer exists. Partial multi-select responses must meet their configured bounds; an unanswered question is omitted until valid. Final required questions cannot be omitted. Body limits are 40 KB for answers and 200 KB for drafts.

Revision conflicts do not silently reload/overwrite local changes. The UI retains local input and offers explicit reload of the newer server version. Saves show saving/saved/unsaved status; failed requests can be retried. Refresh resumes with the established session. If a guest cookie is lost, an ID or nickname cannot recover ownership; start a new attempt. Signing in changes the active principal; guest attempts are not silently transferred into the account.

Registered recent-history UI lists up to 50 completed attempts, all within seven days. No long-term history policy is implied. Solo results report entertainment-only category counts, mean scale responses, option distribution and deterministic observations, never compatibility. Draft preview runs only in memory and sends no answers. No group, admin publication, export, checkout or payment endpoints are implemented.
